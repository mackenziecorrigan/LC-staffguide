01 · When to use it

Spot the moment.

If you notice one of these, pause and ask: could an assistant take the first pass?

The blank page

Starting is the hardest part. Ask for a rough draft, an outline, or ten options to react to.

The messy pile

Notes, emails, or brain dumps that need structure: action items, timelines, checklists, tables.

The repeat task

Anything you have done three times, like weekly updates or event checklists, can become a reusable prompt.

Same thing, new format

One message needed as an email, a slide, a text, and a social post, or reworded for a different audience.

The sounding board

Think out loud with something that asks you questions, challenges the plan, or imagines what could go wrong.

The unfamiliar topic

Get oriented fast with plain-language explanations and smart questions to ask an expert.
